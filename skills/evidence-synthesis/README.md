# evidence-synthesis

Turns a pile of client material into findings the client can check: a source inventory with limits, a findings table where every row has evidence and an effect, an evidence-limits section, a client-safe appendix, and an hour ledger against the weekly cap. First run: an eight-week discovery at 20 hours a week (some weeks authorized to 30), 13 interviews and six other source types, delivered 4 August 2026 as five deliverables and four appendices.

Install with the rest of the library: `npx skills add mpiv-ai/mpiv-skills --skill evidence-synthesis`, or point Claude at [SKILL.md](SKILL.md).
