# mpiv-skill-creator

Turns a consulting method that has run on real work into a skill in this library. Checks it against the Agent Skills spec and the Claude Code plugin rules as of the date in [references/official-guidance.md](references/official-guidance.md). First used 3 September 2026 on research-first-outreach, then on interview-to-brief and evidence-synthesis.

Install with the rest of the library: `npx skills add mpiv-ai/mpiv-skills --skill mpiv-skill-creator`, or point Claude at [SKILL.md](SKILL.md).
