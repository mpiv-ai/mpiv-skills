# interview-to-brief

Runs a research interview from the guide the day before to the reply that carries every promise: findings from the transcript, a scroll brief in the participant's words, a sourced themes memo with named gaps, unlisted hosting, a threaded reply draft, and a promises table checked by a script. First run 2026-09-02: 42-minute call, brief and 22-source memo delivered the next day.

Install with the rest of the library: `npx skills add mpiv-ai/mpiv-skills --skill interview-to-brief`, or point Claude at [SKILL.md](SKILL.md).
